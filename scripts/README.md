# scripts · 工具脚本 🛠️

**职责**：项目生命周期里的各种自动化脚本。

## 现有/规划

| 脚本 | 说明 |
|------|------|
| `fetch-avatars.sh` | 下载数字人素材（**AV-03 已手动下载 Pexels 样片就位，脚本暂缓**；后补真实素材需可重复拉取时再实现） |
| `test-summary.mjs` | 测试报告聚合（暂停中，恢复测试时启用） |

## 约定

- 脚本放本目录，不放模块内（模块内只放业务代码）
- 需要密钥的脚本统一读 `.env`，不硬编码
- 命名规范：`<动作>-<对象>.sh/.mjs`，如 `fetch-avatars.sh`
