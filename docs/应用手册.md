## 1. 项目概述

### 1.1 这是什么？

赛博女友（Cyber Girlfriend）是一个 **AI 数字人语音陪伴应用**——打开浏览器，就能跟一个"活生生"的数字人小姐姐聊天：

- **用语音聊天**：像打电话一样，她边说边显示字幕，你随时可以插话打断
- **她有自己的性格**：18 岁元气少女小呆、温柔知心姐姐、干练工作助手…… 多种人设随意切换
- **她会动**：说话时有形象动画（数字人），情绪还会驱动不同的表情片段
- **她能干活**：不只是聊天——问她问题、让她查资料、算东西，她背后接了一个"大脑"（本机 Hermes agent，50+ 工具）真正去执行

### 1.2 目标用户

| 用户群 | 使用场景 |
|--------|----------|
| 想有个"陪伴对象"的用户 | 日常闲聊、倾诉、情感陪伴 |
| 喜欢虚拟角色的用户 | 不同人设切换，角色扮演式对话 |
| 想要"语音助手 + 数字人"的用户 | 语音交互、复杂事务代办（查资料/计算/执行工具） |
| 技术尝鲜用户 | 体验"云端语音 + 本地大脑"的混合 AI 架构 |

### 1.3 核心价值主张

> **"像真人一样的 AI 陪伴"** —— 别的 AI 只是文本框，赛博女友是**看得见、听得懂、记得住、能办事**的数字人。

| 价值 | 说明 |
|------|------|
| 🎙️ **真语音对话** | 全双工实时语音，边说边听、可打断，不是一问一答的录音机 |
| 💃 **看得见** | 数字人形象随情绪变化，字幕 + 波形同步，沉浸感强 |
| 🧠 **真能办事** | 复杂问题由本机"大脑"（Hermes）执行，50+ 工具（终端/文件/网络） |
| 🔒 **隐私友好** | 记忆在**本机**（Hermes 管理），赛博女友侧零存储 |

## 3. 使用指南

### 3.1 启动应用

赛博女友是本地 Web 应用，启动需要两个终端窗口：

```bash
# 终端 1：启动后端（端口 3000）
cd D:/其他资料/赛博女友
npm run dev

# 终端 2：启动前端（端口 5173）
cd D:/其他资料/赛博女友/client
npm run dev
```

启动完成后，浏览器打开：**http://localhost:5173**

> ✅ 看到数字人形象（或卡通占位）+ "待机中"状态 = 启动成功。

### 3.2 快速上手（3 步）

| 步骤 | 操作 | 说明 |
|------|------|------|
| **1. 认识她** | 打开页面，看到数字人形象 | 默认人设是"小呆"（18 岁元气 AI 少女） |
| **2. 说句话** | 点击麦克风按钮开始说话（或直接用文字输入框） | 她听到后会立刻回应，字幕同步显示 |
| **3. 聊天** | 像正常聊天一样对话 | 可以闲聊、提问、让她办事，随时插话打断 |

### 3.3 注册 / 登录

**无需注册登录。** 赛博女友是纯本地应用，打开即用，无账号体系（数据在本机，隐私优先）。

### 3.4 创建或选择角色

1. 打开应用后，在界面中找到**人设选择**区域（通常在顶部或设置菜单）
2. 当前可用角色：

| 角色 | 人设 | 适合场景 |
|------|------|----------|
| **小呆**（默认） | 18 岁元气 AI 少女，活泼呆萌 | 日常陪伴、闲聊、轻松对话 |
| **知心姐姐** | 温柔知性大姐姐，善解人意 | 倾诉、求安慰、情感话题 |
| **助手** | 干练高效工作助手，直接利落 | 办事、查资料、工作场景 |

3. 点击目标角色 → 立即切换（毫秒级生效）
4. 切换后，新角色有**独立的记忆**——她会记得你在当前角色下聊过的事

> 💡 人设是文件化的（角色卡 + 记忆区），后续版本可自由扩展新角色。

### 3.5 设置个性化参数

| 参数 | 当前支持 | 操作位置 |
|------|----------|----------|
| 人设/性格 | 3 档预设（小呆/知心姐姐/助手） | 人设选择区域 |
| 语音 | 默认音色（Qwen-Audio 官方音色），可调 | 配置文件（见 §4） |
| 语言 | 简体中文（默认） | 跟随人设 |

### 3.6 发起并管理对话

**语音对话：**
1. 点击**麦克风按钮**开始说话
2. 说完了松开（或等 VAD 自动检测到你说完）
3. 她开始回应时，**随时可以再开口打断**（支持边说边听）

**文字对话（降级/调试）：**
1. 在底部文字输入框输入内容
2. 按 **Enter**（或点发送按钮）发出
3. 回复会以文字形式展示（无语音播放，用于无麦克风场景）

**管理对话：**
- 打断：直接开口说话即可打断她当前的回应
- 结束：关闭页面即可（应用无持久化，再次打开是全新会话）

### 3.7 调用各功能模块

| 想做什么 | 操作方法 |
|----------|----------|
| 看她说话时的形象变化 | 默认开启——她说话时数字人自动播放，情绪不同片段不同 |
| 看字幕 | 默认开启——她说的每句话都有实时字幕 |
| 看她"干活" | 问她需要执行的任务（如"帮我算一下 XX"），她会先显示"思考中"，然后大脑执行，结果语音/文字返回 |
| 切换角色 | §3.4 人设选择 |
| 用文字代替语音 | §3.6 文字输入框 |

## 4. 设置与配置

### 4.1 用户可调项

| 设置项 | 选项 | 默认值 | 调整方式 |
|--------|------|--------|----------|
| **人设** | 小呆 / 知心姐姐 / 助手 | 小呆 | 界面人设选择（即时生效） |
| **音色** | Qwen-Audio 官方音色列表（longanqian 等） | longanqian | 配置文件 `voice-shell/qwen-audio-client.ts` 的 `voice` 字段 |
| **打断灵敏度** | VAD threshold / 静音时长 | threshold 0.5 / silence 800ms | 配置文件同上的 `turn_detection` |
| **输入转写** | 开/关 | 开（fun-asr） | 配置文件 `input_audio_transcription` |

> 这些高级项（音色/灵敏度/转写）需要编辑代码配置，适合有技术背景的用户；界面可调项目前为**人设切换**。

### 4.2 环境配置（管理员/开发者）

| 配置 | 文件 | 说明 |
|------|------|------|
| DashScope API Key（必填） | `config/apikeys.json` 或 `.env` | 语音壳连接凭证，缺失时语音不可用（文字降级可用） |
| Hermes 大脑 | 本机 Hermes Agent v0.20.0 | 缺失时自动降级纯 Qwen 回答 |
| 数字人素材 | `assets/avatars/`（6 视频 + 8 图） | 缺失时降级卡通占位 |

## 5. 常见问题（FAQ）

### Q1: 打开页面只显示"待机中"，说话没反应？
**原因**：后端服务未启动，或 API Key 未配置。
**解决**：
1. 确认后端终端有 `[app] 赛博女友 API 已启动` 日志（§3.1 两个终端都要跑）
2. 确认 `config/apikeys.json` 有 DashScope Key
3. 用浏览器访问 `http://localhost:3000/api/health`，应返回 `{"status":"ok"}`

### Q2: 发文字消息报 HTTP 500？
**原因**：后端未启动（最常见）或 Hermes 执行异常。
**解决**：
1. 确认后端在跑（`curl http://localhost:3000/api/health` 返回 ok）
2. 确认后端终端日志无报错；Hermes 异常会自动降级，不会一直 500

### Q3: 第一次对话很慢（20~40 秒）？
**原因**：本机 Hermes 大脑冷启动（首次需要加载模型与工具）。
**解决**：
- 这是**已知性能瓶颈**，复杂事务场景本身需要时间（目标 1.5~6s，当前冷启动 12~23s）
- 后续版本会通过 ACP 常驻优化（预计降到 2~5s）
- 简单寒暄（"你好""今天天气怎么样"）会快一些；纯问答类可以直接用文字通道

### Q4: 没看到数字人形象（只有卡通占位）？
**原因**：数字人素材未下载或路径不对。
**解决**：素材在 `assets/avatars/clips/`（Pexels 免费商用素材，6 视频）。缺失时自动降级卡通占位，不影响对话功能。

### Q5: 她"记不住"之前聊的？
**说明**：记忆由 Hermes 管理，**同一人设**下的重要内容会自动沉淀（人设分区记忆）。
**注意**：
- 切换人设 = 切换记忆（各人设独立）
- 如果完全无记忆，检查 Hermes 是否正常运行（降级模式下无记忆）

### Q6: 听不到声音 / 没有声音输出？
**检查**：
1. 浏览器麦克风/扬声器权限是否允许
2. 系统音量是否正常
3. API Key 是否有效（Key 失效会导致语音链路失败）

### Q7: 如何换一个性格/角色？
见 §3.4——在界面上选择"知心姐姐"或"助手"即可，毫秒级切换，且各角色记忆独立。

### Q8: 数据会存到哪里？隐私安全吗？
- 赛博女友侧**零持久化**（不建数据库、不存聊天记录）
- 记忆与事务数据在本机 Hermes 的独立 profile（`cyber-girlfriend`）中，**与主 profile 双向隔离**
- 语音走云端 Qwen-Audio（阿里百炼），按官方隐私政策处理
