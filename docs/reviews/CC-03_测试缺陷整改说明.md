### 阶段 1：修复 DEF-A-01（orchestrator 降级测试）
1. 打开 `app/server/orchestrator-degradation-test.ts`
2. 定位用例 3b / 4b（M-A-TC-009 / M-A-TC-012）
3. 原因：CC-01 整改 L9 将降级失败提示脱敏为"大脑开小差了，稍后再试试？"，测试仍断言包含具体错误文本

5. 验证：`node --experimental-strip-types app/server/orchestrator-degradation-test.ts`

### 阶段 2：修复 DEF-A-02（ws-smoke personasDir）
1. 打开 `app/server/ws-smoke-test.ts`
2. 原因：CC-01 整改 H6 新增 `startsWith(personasDir)` 校验，测试环境 personasDir 配置与实际路径不匹配，导致"非法人设 id:xiaodai(路径越界)"
3. **修改**：检查测试中传入的 personasDir 配置——应指向实际人设目录（`C:/Users/chipsine/AppData/Local/hermes/profiles/cyber-girlfriend/personas/`）或使用有效的测试人设目录；若测试无法用真实目录，可在测试中构造临时人设目录并设置 `personasDir` 指向它
4. 验证：`node --experimental-strip-types app/server/ws-smoke-test.ts`（②③④ 应 PASS）

### 阶段 3：处理 DEF-V-01（gateway 二进制帧）
1. 打开 `voice-shell/gateway-unit-test.ts`
2. 定位"二进制音频帧直通 sendAudio"用例（M-V-TC-042）
3. 原因：当前前端通过 base64 JSON 发送音频（非二进制帧），gateway 仅处理 text 帧；此用例测试的是架构不需要的场景
4. **修改（二选一）**：
   - 方案 A（推荐）：删除该用例，并在测试文件注释说明"前端用 base64 JSON，二进制帧直通为设计边界，暂不支持"
   - 方案 B：gateway 增加 Buffer 帧识别分支（仅当确认未来需要时）
5. 验证：`node --experimental-strip-types voice-shell/gateway-unit-test.ts`（26/26 通过）
