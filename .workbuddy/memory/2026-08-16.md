- **任务**：清除赛博女友项目中的 log 文件和其他冗余文件。老板确认"全部清理"（A 日志 + B npm 缓存 + C 临时目录 + D 测试日志）。
- **清理成果（约 196MB，全部移入回收站可恢复）**：
  - 28 个日志文件：根目录 `.backend*.log` ×18 + `client/.frontend*.log`/`.tmp-vite.log` ×8 + `docs/reviews/test-reports/subtitle-capture-*.log` ×2

  - 临时目录 ×2：`.tmp-probe/`（probe 测试脚本）、`client/.tmp/`（旧构建 dist-old-*、vite-out、voice-test.mjs）
- **保留**：`client/dist/`（构建产物）、`docs/templates/`（模板）、`单模块测试报告.md`（文档）
- **技术要点（可复用）**：
  - Windows 下本会话安全策略**拦截** `Add-Type`、`[Reflection.Assembly]::Load*`、COM 对象实例化 → PowerShell 回收站路线全废
  - `send2trash` 在 Windows 走 legacy 后端会把路径转 8.3 短路径（`GetShortPathNameW`），本项目中文路径下转换失败报错/部分成功，不可靠
  - **可靠方案**：Python `ctypes` 直接调 `shell32.SHFileOperationW`，`wFunc=FO_DELETE(3)` + `fFlags=FOF_ALLOWUNDO(0x40)|FOF_NOCONFIRMATION|FOF_SILENT|FOF_NOERRORUI`，`pFrom` 传双 null 结尾缓冲 → 移入回收站，支持目录递归；对占用文件返回 0x78 拒绝访问（单独处理即可）
  - 删除后 bash+python 双重验证，全部清除干净；项目内已无 log/缓存/临时目录（node_modules 内不动）
