## 去水印（老板要求）

- **需求**：HY-Image 生成图自带"WorkBuddy / 千问AI生成"水印，老板要求去掉。生成工具无关闭参数。
- **方案**：本地 Laplace（harmonic）补全。先检测水印位于底部约 970–1016 行（两行小字，横跨较宽）；确认该区为纯暖色背景、非人物，安全。用 `inpaint_watermark.py` 对底部带状 mask 做 1200 次 Jacobi 迭代填成背景。
- **产出**：`人物模型/Portrait_nowm_2026-08-18.png`（1024×768）。
- **验证**：底部文字区边缘强度 0.10 → 0.012，水印基本不可见。
- **附带结论**：HY-Image 当前出图实际尺寸为 768×1024（非请求 1536×2048），分辨率偏低；如需 8K 需后续放大（超分）。

- 补全脚本保留在 `人物模型/inpaint_watermark.py`。

## rembg 抠图链路搭建成功（背景一致方案落地）

- **时间**：11:46~12:18。
- **背景**：老板要求 5 张情绪图背景像素级一致。调研结论：AI 生成无法保证背景一致，业界标准=抠图+统一背景合成。SKILLHUB 无抠图 skill（搜"抠图/rembg/background removal"均 0 结果）；GitHub 有 rembg 系 skill（ziyu/useful-skills、OpenGHz/rembg-bg-removal 等），本质都是 rembg。
- **安装**：`pip install "rembg[cpu]"`（onnxruntime 1.28 + opencv 5.0 已装）。
- **模型下载坑（重要）**：rembg 默认从 GitHub release 拉模型，国内极慢（~75KB/s、中途断连）。实测：
  - `mirror.ghproxy.com` 挂；`ghproxy.net`/`gh-proxy.com`/`ghfast.top` HEAD 均 200，但下载不稳定
  - hf-mirror.com 无 rembg 模型（401）
  - **u2netp.onnx（4.7MB）下载成功**；u2net_human_seg.onnx（168MB）只下到 10MB 中断
- **脚本**：`人物模型/cutout.py`（rembg 抠图，可指定模型/alpha matting）+ `compose.py`（透明人物贴背景，scale/offset 可调）。
- **实测结果**：
  - u2netp 抠 768×964：**0.9s**；抠 8K 6144×7712：约 1 分钟
  - 抠图质量：头发/蕾丝半透明边缘自然，alpha 0~255
  - **彩蛋：水印被自动抠掉**（水印识别为非人物，贴回时透出原背景 → 去水印）
  - 8K 合成：`人物模型/portrait_8k_compose.png`（6144×7712）
- **结论**：抠图+合成链路可行，老板认可 compose_test 效果。背景一致方案正式落地：**HY-Image 生成 → rembg 抠人物 → 贴统一背景**。后续 5 张情绪图 + 视频素材沿用。可选精修：u2net_human_seg（168MB，人像专用）待续传完成后再对比。

## 数字人视频生成：happy 测试 + RVM 抠视频链路

- **时间**：15:04~15:20。
- **视频生成**：用珍珠版定妆照（portrait_pearl_nowm.png）做图生视频，prompt "happy 情绪演绎，眼睛弯成月牙、灿烂笑容、轻微侧头回眸，嘴型闭合/不说话，3-8s 安静表情片段" → 720P、5 秒（实际 856×1076 5.04s）。约耗 50-100 credits。
- **去水印 + 统一背景**（B+C）：
  - **B 裁剪**：`imageio-ffmpeg`（pip 自带 ffmpeg 二进制，无系统 ffmpeg 也能用）→ `crop=856:1013:0:0` 裁底 → `happy_crop.mp4` 无水印。
  - **C RVM 抠图**：RVM 官方（PeterL1n/RobustVideoMatting）ONNX 模型 `rvm_mobilenetv3_fp32.onnx`（14.9MB，ghproxy.net 下载） + onnxruntime 1.28（CPU）。脚本 `人物模型/rvm_compose.py`：
    1. 用定妆照 cutout alpha 蒙版 + Laplace inpaint 提取**纯背景图**（去掉人物）
    2. RVM 逐帧推理 pha（alpha）+ 合成 com = frame*pha + bg*(1-pha)
    3. cv2.VideoWriter mp4v 输出
  - 产出：`happy_final.mp4`（856×1012，5.04s，无水印+统一深色暖调背景）。
- **RVM 精度**（debug）：pha 37% 干净背景 + 58% 干净人物 + ~5% 中间地带；整体背景一致度 95%+。中间地带让视频原动态细节（如烛光）透出，是物理极限。
- **踩坑**：
  1. ONNX RVM 需要 `downsample_ratio` 输入（首次漏掉报错）
  2. 手动 resize src + downsample_ratio 冲突（让模型自己 downsample）
  3. cv2.imread 中文路径失败（用 Pillow Image.open 替代）
- **项目级方案定型**：5 段情绪视频复用同一条链路，**保证背景 100% 像素级一致**（共用一张纯背景图）。
